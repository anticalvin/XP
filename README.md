# XP NEXT 🌟

XP is a playful real-life productivity app. This repository contains the GitHub Pages demo of XP NEXT, connected to the separate Supabase XP project `ugoaqdsnizudjifghtoz` using a publishable client key (never a service-role secret).

Open the site at https://anticalvin.github.io/XP/ once GitHub Pages is enabled for the `main` branch, repository root.

The app stores solo tasks, XP, and projects locally in your browser. Social auth and friendships use Supabase and require internet and confirmed email if enabled. Rewards are self-reported and not independently verified. No paid AI APIs are used.

To run locally, use a static HTTP server, for example `python -m http.server 8000` and visit http://localhost:8000. Opening a modular app using `file://` is not supported by all browsers.

The initial published site is a small no-build web demo. The more extensive XP NEXT alpha source bundle is available separately from the ChatGPT project session. This repository is not yet a production release.
