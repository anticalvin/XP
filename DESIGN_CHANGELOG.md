# XP NEXT visual overhaul: design decisions

- **Identity:** Replaced pastel lavender and rounded toy-like components with near-black surfaces, precise rules, a singular signal-green accent and bold, condensed-feeling typography.
- **Navigation:** Removed functional emoji icons; desktop and mobile share the same locally-authored stroke SVGs.
- **Copy:** Replaced generic motivational phrasing and routine celebrations with clear task and account language. Stronger titles are reserved for focal surfaces.
- **Today:** Restructured into next action, queue, project summaries, progress stats and recommendation/energy controls.
- **Projects and Paths:** Revised compact cards; path labels render without emoji while persisted category values stay unchanged.
- **Friends:** Improved search explanations, request status and loading/error states.
- **Profile:** Honest description of guest storage versus signed-in cloud backup, cleaner account controls, activity log and accessible seven-day summary.
- **Focus:** Larger high-contrast timer, concise controls, consistent dialog styling and keyboard dismissal.
- **Responsive:** Dedicated mobile navigation, safe-area padding, smaller-screen heading sizing and reduced-motion support.
- **Not claimed:** No original illustrated avatar system, no server-side XP validation, no offline syncing, no browser-based multi-account QA in this pass.
